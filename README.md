# 🌟 Mohit Portfolio

A modern, animated personal portfolio built to showcase **Mohit Agarwal’s** profile, achievements, case studies, and contact details in an engaging, recruiter-friendly format.

## 🚀 Project Overview

This repository contains Mohit’s portfolio website, focused on presenting the intersection of **business strategy + technology** through a bold, interactive UI.

> Main app location: [`/portfolio-v2`](./portfolio-v2)

## 🧰 Tech Stack

- ⚡ **Next.js 14**
- ⚛️ **React 18**
- 🔷 **TypeScript**
- 🎨 **Tailwind CSS**
- 🎞️ **Framer Motion**

## ✨ Key Features

- 🐉 Cinematic intro experience (`DragonIntro`)
- 🧭 Smooth section-based navigation with active states
- 👤 Hero section with animated stats and rotating role highlights
- 📊 Case studies and achievement timelines
- 🎓 Education and 📜 certificates showcase
- ⚡ Extracurricular highlights
- 💌 Contact section with social links and interactive form states
- 📱 Responsive design for desktop and mobile

## 🛠️ Installation & Setup

### 1) Clone and enter the project

```bash
git clone https://github.com/mohit4215/portfolio.git
cd portfolio/portfolio-v2
```

### 2) Install dependencies

```bash
npm install
```

### 3) Start local development

```bash
npm run dev
```

Open: `http://localhost:3000`

## 🔄 Development Workflow

From `/portfolio-v2`:

```bash
npm run dev    # Start dev server
npm run lint   # Run lint checks
npm run build  # Create production build
npm run start  # Run production server
```

Suggested flow:
1. Create a feature branch
2. Build UI/components
3. Run `npm run lint` and `npm run build`
4. Open PR and deploy

## 🌍 Deployment Options

### Option A: Vercel (recommended)

This repo includes `vercel.json` for Next.js deployment.

1. Import the repository into Vercel
2. Set project root to `portfolio-v2`
3. Deploy

### Option B: GitHub Pages (static export)

The repository includes `next.config.ghpages.mjs` with export settings (`output: 'export'`, base path, asset prefix).

Typical approach:
1. Use the GitHub Pages config as your active `next.config.mjs`
2. Run `npm run build`
3. Publish the generated static output
